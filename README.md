

# Exploratory Data Analysis and Preprocessing on the Iris Dataset

This repository provides a comprehensive walkthrough of **exploratory data analysis (EDA)**, **feature scaling**, **label encoding**, and **data splitting** on the classic **Iris dataset** using Python libraries such as `pandas`, `seaborn`, and `scikit-learn`.

---

##  Dataset

The [Iris dataset](https://archive.ics.uci.edu/ml/datasets/iris) is a famous multivariate dataset introduced by Ronald A. Fisher. It includes:
- 150 samples
- 4 features: sepal length, sepal width, petal length, petal width
- 3 classes: Setosa, Versicolor, Virginica

---

## 🔧 Features Implemented

-  Basic data exploration and statistical summary
-  Null value check
-  Histograms and pair plots for visual understanding
-  StandardScaler and MinMaxScaler feature scaling
-  Label encoding of species column
-  Train-test split using `train_test_split`

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/iris-eda-preprocessing.git

   ```

2. Run the script:

   ```bash
   python iris_preprocessing.py
   ```

Make sure all required libraries are installed. You can install them via:
